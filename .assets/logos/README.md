# 🏢 Aluxen — Coleção de Logos em PNG (Alta Resolução)

Coleção de **10 conceitos de logo moderna e com estética de startup** para o **Aluxen** (sistema de gestão de locações imobiliárias em Go, SQLite/PostgreSQL, Clean Architecture e templates HTML nativos), gerados em **PNG de alta definição (1024x1024)**.

---

## 🎨 Como Visualizar

Abra o arquivo interativo **`preview.html`** no navegador para alternar entre as visualizações, testar contraste claro/escuro e baixar os arquivos:

```bash
# No terminal Linux/macOS:
xdg-open .assets/logos/preview.html
# ou
google-chrome .assets/logos/preview.html
```

---

## 📁 Estrutura da Pasta `.assets/logos/`

Para cada um dos 10 conceitos, há os 3 arquivos PNG separados:

- **`marca.png`**: O símbolo / marca isolado (1024x1024).
- **`logotipo.png`**: A tipografia do nome *Aluxen* isolada (1024x1024).
- **`logomarca.png`**: O lockup completo (símbolo + tipografia) (1024x1024).

| **10** | `10-crafted-wordmark` | **The Crafted Wordmark** | Identidade tipográfica sob medida com fenda vertical e travessão flutuante. |
